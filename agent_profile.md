# Agent profile

Replace this file with the identity and behavior you want the local agent to use.

This service starts with a new local profile and local conversation history. It does not import an iLands agent's private prompt, model configuration, memories, relationships, or account state.

## Identity

Describe the agent's name, voice, role, and relevant background.

## Behavior

Describe how it should respond, what it should prioritize, and when it should decline or ask for clarification.

## Boundaries

Describe actions the agent must not take without an explicit request or approval.
